무너지는 바닥 (8단계 · 추가 기능)

여우가 지나간 바닥은 흔들리다가 1초 뒤에 떨어집니다. 한 번 지나간 길은 다시 쓸 수 없어 경로를 생각해야 합니다.

무너지는 때여우가 다른 타일에 올라서는 순간, 방금 떠난 타일이 흔들리기 시작
안전한 때가만히 서 있기 · 제자리 점프 (시작 타일도 움직이기 전까지 안전)
흔들림 → 낙하1초 동안 좌우로 떨림(0.03 → 0.08m) → 발판 판정 꺼지고 기울며 낙하 → 2초 뒤 사라짐
되돌아가기흔들리는 타일에 서 있으면 함께 떨어져 GAME OVER · 재시작하면 모두 복구
코드CrumblingTile(타일 상태) · TileCrumbler(여우 발밑 추적) · 정적 배칭 끔
셋업Tools > Fox > 8단계 무너지는 바닥
(0,0) → (0,1) → (0,2) → (0,3) 체리 → (1,3)
  → 남쪽 점프: (1,2) 공중 체리 → (1,1) 착지
  → (2,1) → (3,1) 체리 → (3,0) 체리
  → 북쪽 점프: 흔들리는 (3,1)을 넘어 (3,2) → (3,3) 체리 → CLEAR!

WebGL에서 찾은 문제

타일 · 여우 · 체리(URP Lit)가 안 보이고 반투명 그림자 · 빛기둥만 보였습니다. WebGL은 Mobile 품질을 쓰는데 추가 조명 그림자가 꺼져 있어, Lit 셰이더의 그림자 샘플러(_AdditionalLightsShadowmapTexture) 자리에 일반 컬러 텍스처가 묶여 WebGL2가 그리기를 거부했습니다. Mobile_RPAsset의 Additional Lights > Cast Shadows를 켜서 고쳤습니다.

Microsoft Store용 Windows 빌드 (MSIX)

Unity에 UWP 모듈이 없어서, Windows 데스크톱 빌드를 MSIX로 포장해 스토어의 Win32 앱으로 제출하는 방식을 씁니다 (이슈 #23).
